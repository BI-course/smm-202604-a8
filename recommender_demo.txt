API behavior
POST /api/v1/models/music-track-recommender/predictions
Body: {"track_ids": ["M01", "M03"], "top_n": 5}
Match all rules whose full antecedent is among the played tracks. Exclude
already-played tracks, combine evidence from all matching rules by retaining
the strongest confidence/lift/support score per candidate, then rank.
Ties use track ID for deterministic output. top_n defaults to 5 (range 1-20).
Invalid, missing, empty or unknown track IDs return HTTP 400 JSON errors.
Known inputs with no eligible recommendations return HTTP 200 and an empty list.
